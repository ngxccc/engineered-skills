# Tier 1 PR Specification (Patch / Minor)

Low ceremony, high efficiency template for minor fixes, documentation updates, and trivial dependency bumps.

---

## Title Standard

```
<type>(<scope>): <summary>
```

Example: `docs(readme): fix typo in quick start guide`

---

## PR Body Template

```markdown
## Summary

Quick documentation / patch update.

## Checklist

- [x] Manual check completed
```
